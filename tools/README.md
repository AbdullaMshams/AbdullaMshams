# Regenerating the profile images

Everything in `assets/` except the three `design-*.png` source boards is generated by `build_svgs.py`.
All SVG text is converted to `<path>` outlines (fontTools + HarfBuzz), so the SVGs contain no `<text>` and no webfonts.

## Setup

```bash
pip install fonttools uharfbuzz skia-pathops pillow
```

## Run

```bash
python3 tools/build_svgs.py
```

Outputs: `hero`, `section-01..04`, `card-*`, `stack`, `footer` as `-dark.svg` / `-light.svg`, plus `shot-showroom-*.png` and `design-showcase-*.png`.

## Where things live

- `fonts/`: Alexandria (700, 800, 500) and JetBrains Mono (500) variable fonts, SIL Open Font License (licence files included).
- `source/`: raw images used for the PNG panels (Showroom screenshot, Dubrah and Real-Time Forum boards).
- Palette and copy (card titles, chips, stack rows) are at the top and bottom of `build_svgs.py`.

PNGs are palette-quantised to stay under 300 KB. After editing, check: `find assets -size +300k`, `xmllint --noout assets/*.svg`, and no U+2013 or U+2014 characters.
